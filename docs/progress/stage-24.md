# 阶段 24：计算得到的独热寄存器

日期：2026-10-27　版本：0.24.0

## 1. 完成的功能

阶段 23 只认得"各分支写常量或保持"的独热寄存器。本阶段把判定改为对时钟周期的归纳证明：假设当前寄存器（以及它复制的寄存器）至多一位为 1，证明 D 输入能取到的每个值也至多一位为 1，再加上上电值和复位值至多一位为 1。

新增能识别的写法：
- **位复制、旋转、移位**：D 的每一位要么是常量 0，要么是同一寄存器的某一位，且每个源位最多用一次。覆盖保持、环形移位 `{sel[2:0], sel[3]}`、补零移位、整体复制。
- **复制另一个独热寄存器**：源寄存器必须是同一时钟网络、同一边沿。异时钟的复制不接受，因为采样可能同时看到旧值和新值的两个 1。多个寄存器组成的环（`mid <= ring2; ring2 <= rot(mid)`）按归纳一起证明。
- **译码器**：独热值经 `<<`、`>>` 移任意位数，例如 `1 << idx`。算术右移 `>>>` 只在符号位为 0 时接受。
- **按下标置位**：`n = 0; n[idx] = 1'b1;`（全零基值加一个单比特插入）。

### 修正：上电初值

以前只检查复位值，忽略了声明初值（FPGA 上电值）。`reg [1:0] sel = 2'b11;` 上电时两位都为 1，此前会被当成独热。现在初值也要求至多一位为 1（没有初值的位按 0 处理）。

## 2. 结果

- 旋转、补零移位、译码、按下标置位、同时钟复制作为选择信号的与或选择器：不再报告重汇聚。
- 移入数据位、一个位用两次、译码 `2'b11`、在已有 1 的基值上置位、上电值有两位为 1：仍然报告。
- 新增 `SeqGraph` 单元测试直接检验判定：9 个应接受、10 个应拒绝的寄存器，包括异时钟复制、补 1 移位、负数算术右移、单比特寄存器。

## 3. 修改的文件

- `src/cdc/SeqGraph.cpp`：`atMostOneHot` 改为归纳证明（位复制、同时钟复制、移位、单比特插入、上电初值）。
- `tests/cdc/test_cdc.cpp`：独热判定的单元测试。
- `tests/cdc/test_cdc_advanced.cpp`：端到端正例和负例。
- 文档：`docs/rules/CDC-005.md`。

## 4. 测试有效性

- 换回阶段 23 的实现：新增的 5 个负例全部失败。
- 去掉同时钟要求：异时钟复制的单元测试失败。
- 不检查上电初值：上电值有两位为 1 的单元测试失败。

## 5. 已知限制

- 用加法、查表等方式计算出的独热值不能识别。
- 依赖数据的互斥不能识别。
- 同时钟只按"时钟驱动源与边沿完全相同"判断，经过缓冲器重新命名的同一时钟会被保守地当作不同时钟。
