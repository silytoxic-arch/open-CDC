# CDC-010: Crossing between clocks with an unknown relation

| Field | Value |
|---|---|
| Default severity | Warning |
| Result status | NeedsReview |
| Implemented in | `src/rules/RuleEngine.cpp` (`Cdc010`) |
| Tests | `tests/cdc/test_cdc.cpp` (tag `[CDC-010]`), `tests/cdc/test_cdc_advanced.cpp`, `examples/cdc_rules` |

## Purpose
Point out crossings whose clocks come from independent sources that no constraint relates. OpenCDC never assumes two clocks are asynchronous just because they have different names. Without constraints, their relation is **unknown**.

## Applicability
Every crossing path whose clock pair has the relation `unknown`, while `options.unknownClockRelation` is `report` (the default).

## Detection algorithm
1. Clock analysis (stage 3) assigns every clock pair a relation with a reason.
2. With policy `report`, unknown pairs are analyzed as if asynchronous.
3. Every such path gets a CDC-010 hit with the reason, and every other hit on the path is downgraded from Violation or PotentialRisk to NeedsReview (PotentialRisk since stage 5).

## Policy
| `unknownClockRelation` | Effect |
|---|---|
| `report` (default) | Analyze as asynchronous; add CDC-010; other violations become NeedsReview |
| `assume_async` | Analyze as asynchronous; no CDC-010; other violations stay violations |
| `assume_sync` | No crossings between such clocks |

## False-positive limits
The hit disappears once the relation is constrained (`set_clock_groups`, `create_generated_clock`), or when the policy is changed.

## Test cases
- Positive: two primary clocks without constraints.
- Negative: the same design with `set_clock_groups -asynchronous`, and with policy `assume_async`.

## Fix
Describe the clocks in the constraint file. Use `set_clock_groups -asynchronous` for independent clocks, and `create_generated_clock` for clocks derived from another clock.

## Waivers
A reviewed hit of this rule can be waived by rule id, path fingerprint, or source/destination name (see [docs/waivers.md](../waivers.md)). A waived hit stays in all reports, marked with its waiver, and no longer counts as a violation.
