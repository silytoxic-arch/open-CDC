# Built-in vendor primitive models

OpenCDC models the FPGA vendor primitives that matter for clock-domain-crossing analysis. A model is added to the compilation only when the design instantiates the primitive and the sources do not define a module of that name; a user module of the same name always wins. The models describe register-transfer structure (which pins are clocks, which signals are registered in which clock, which outputs have no clock domain), not the full functional behavior. They are therefore not usable for simulation.

Common rules:

- Parameters a model does not use are accepted and ignored. VHDL aggregates without a type (for example `INIT_00 => (others => '0')`) are skipped.
- A connection to a pin the model does not have is reported once per pin as `FE-PRIMITIVE-PORT` (information) and ignored. This applies to cascade, ECC, sleep and test pins.
- Unconnected inputs and outputs of primitives are not reported.
- `ASYNC_REG` on an instance (Verilog attribute, or VHDL `attribute ASYNC_REG of s1 : label is "TRUE"`) marks a synchronizer stage.
- VHDL designs reach the models through:
  - `library unisim; use unisim.vcomponents.all;`
  - `library xpm; use xpm.vcomponents.all;`
  - `library altera_mf; use altera_mf.altera_mf_components.all;`
  - Lattice: `library ecp5u; use ecp5u.components.all;` (also `ecp5um`, `ecp5um5g`), `library sb_ice40_components_syn; use sb_ice40_components_syn.components.all;` (iCEcube2) and `library iCE40UP; use iCE40UP.components.all;` (Radiant);
  - Gowin: `library gw1n; use gw1n.components.all;` (also `gw1nr`, `gw1ns`, `gw1nz`, `gw2a`, `gw2ar`, `gw5a`, `gw5ast`).
- A component package is added only for a library the VHDL code names and the project does not provide itself.
- "No clock domain" means the signal is driven by the internal black box `opencdc_async_source`. Such a signal used as an asynchronous reset is checked by CDC-006. As data, it is listed as `CDC-NO-DOMAIN` and not checked.

Sources:
- `src/frontend/primitives/*.v` (Verilog models) and `*.vhd` (component packages);
- MMCM/PLL models are generated per use in `src/frontend/Primitives.cpp`;
- GT models are generated by `tools/primitives/gen_gt.py`.

## Xilinx UNISIM

| Primitive | Model | Notes |
|---|---|---|
| `FDRE`, `FDSE`, `FDCE`, `FDPE`, `FD`, `FDE`, `FDR`, `FDS`, `FDC`, `FDP`, `FDCPE` | Flip-flop with its clock enable, synchronous or asynchronous set/reset; `IS_*_INVERTED` honored | `CE`/`R`/`S` tied to their inactive level are no controls, so an `FDRE` chain is a flop chain |
| `LDCE`, `LDPE` | Latch with clear / preset | |
| `BUFG`, `BUFGCE`, `BUFGCE_1`, `BUFGMUX`, `BUFGMUX_CTRL`, `BUFGCTRL`, `BUFH`, `BUFHCE`, `BUFIO`, `BUFG_GT` | Clock buffers: wires, gates and clock multiplexers | A `BUFGMUX` output carries both input clocks |
| `BUFR` | `BUFR_DIVIDE` `"BYPASS"`/`"1"`: wire; `"2"`–`"8"`: divided clock, period = input period × divide | |
| `BUFGCE_DIV` | `BUFGCE_DIVIDE` 1: wire; 2–8: divided clock | |
| `IBUF`, `IBUFG`, `IBUFDS`, `IBUFGDS`, `OBUF`, `OBUFT`, `OBUFDS`, `OBUFTDS`, `IOBUF`, `IOBUFDS` | I/O buffers: wires | |
| `IBUFDS_GTE2`, `IBUFDS_GTE3`, `IBUFDS_GTE4` | Reference clock buffers: `O` and `ODIV2` follow `I` | The `ODIV2` divider is not modelled |
| `SRL16E`, `SRLC32E` | Shift register in the clock domain of `CLK` | |
| `LUT1`, `LUT2`, `LUT3`, `LUT4`, `LUT5`, `LUT6`, `LUT6_2`, `MUXF7`, `MUXF8`, `VCC`, `GND` | Combinational | |
| `IDDR`, `IDDRE1` | Falling-edge capture, rising-edge outputs `Q1`/`Q2` | |
| `ODDR`, `ODDRE1` | Two rising-edge registers that both reach `Q` | |
| `IDELAYE2`, `IDELAYE3`, `ODELAYE2`, `ODELAYE3` | Data path is a wire; tap counter `CNTVALUEOUT` in the control clock (`C` / `CLK`) | |
| `IDELAYCTRL` | `RDY` has no clock domain | |
| `ISERDESE2`, `ISERDESE3` | Serial data shifted on `CLK`, parallel word registered on `CLKDIV` | `CLK` and `CLKDIV` come from one source, so they are not a crossing. The `ISERDESE3` FIFO is a hard synchronizer: the word is given in the `CLKDIV` domain. `NETWORKING`/`BITSLIP` timing is approximate. |
| `OSERDESE2`, `OSERDESE3` | Word registered on `CLKDIV`, shifted out on `CLK` | Tristate byte control is approximate |
| `RAMB18E1`, `RAMB36E1`, `RAMB18E2`, `RAMB36E2` | Port A in `CLKARDCLK`, port B in `CLKBWRCLK`; each port writes its own array and both ports read both arrays | Data written by one port and read by the other is a crossing. A port whose write enable is tied off writes nothing. Cascade and ECC pins are ignored; ECC outputs are 0. |
| `URAM288` | One clock for both ports | |
| `DSP48E1`, `DSP48E2` | `P` and the cascade outputs depend on all data and control inputs; registered on `CLK` (`CEP` enable, `RSTP` reset) when any pipeline register (`AREG`, `BREG`, `CREG`, `DREG`, `ADREG`, `MREG`, `PREG`) is on, otherwise combinational | The individual pipeline stages are not modelled |
| `BSCANE2` | `TCK` is a clock source of its own (relation unknown until constrained); `DRCK` = `TCK`; `SEL`, `SHIFT`, `CAPTURE`, `UPDATE`, `RESET`, `RUNTEST`, `TDI`, `TMS` change in the `TCK` domain | The TAP controller is not modelled |
| `MMCME2/3/4_BASE`, `MMCME2/3/4_ADV`, `PLLE2/3/4_BASE`, `PLLE2/3/4_ADV` | Every `CLKOUT*`/`CLKFBOUT` is a clock derived from `CLKIN1` (`CLKIN` for PLLE3/4), named after the pin; `LOCKED` has no clock domain | Period = input period × `DIVCLK_DIVIDE` × `CLKOUTn_DIVIDE[_F]` / `CLKFBOUT_MULT[_F]`. The input period comes from the input clock, or from `CLKIN1_PERIOD` when the input clock has none. Phase shift, duty cycle and DRP are not modelled. |
| `GTXE2_CHANNEL`, `GTHE2_CHANNEL`, `GTPE2_CHANNEL`, `GTHE3_CHANNEL`, `GTHE4_CHANNEL`, `GTYE3_CHANNEL`, `GTYE4_CHANNEL` | `RXOUTCLK`, `TXOUTCLK`, `RXOUTCLKPCS`, `TXOUTCLKPCS` are clock sources of their own (named `inst.RXOUTCLK` …); `TXDATA` captured on `TXUSRCLK2`, `RXDATA` registered on `RXUSRCLK2`; reset-done and lock outputs have no clock domain; DRP is combinational | The relation of a GT clock to fabric clocks is unknown until constrained (CDC-010). Vivado-style `create_clock … [get_pins ch/RXOUTCLK]` works. About 70 of the most used pins are modelled; the rest are ignored. |
| `GTXE2_COMMON`, `GTHE2_COMMON`, `GTPE2_COMMON`, `GTHE3_COMMON`, `GTHE4_COMMON`, `GTYE3_COMMON`, `GTYE4_COMMON` | PLL output clocks derived from the first reference clock input; reference outputs pass it through; lock outputs have no clock domain | |

## Xilinx XPM

| Macro | Model | Recognized as |
|---|---|---|
| `xpm_cdc_single` | `DEST_SYNC_FF` flop chain (optional source register) | 2/3/N-flop synchronizer |
| `xpm_cdc_array_single` | One chain per bit | Flop chains; CDC-008 if the bits form one value |
| `xpm_cdc_gray` | Binary→Gray source register, one chain per bit, Gray→binary | Gray (the source encoding is proven) |
| `xpm_cdc_handshake` | Request/acknowledge with data held | Handshake |
| `xpm_cdc_pulse` | Toggle + edge detection | Toggle |
| `xpm_cdc_async_rst`, `xpm_cdc_sync_rst` | Reset synchronizers | Reset synchronizer / flop chain |

| `xpm_memory_sdpram`, `xpm_memory_tdpram`, `xpm_memory_dpdistram` | As block RAM; `CLOCKING_MODE = "independent_clock"` uses `clkb` for port B, `"common_clock"` uses `clka` | `READ_LATENCY` output pipeline; `dpdistram` latency 0 is an asynchronous read |
| `xpm_memory_spram` | Single-port memory | |

## Intel

| Primitive | Model |
|---|---|
| `altera_std_synchronizer`, `altera_std_synchronizer_bundle` | `depth`-flop chain (per bit) |
| `altera_reset_synchronizer` | Reset synchronizer (`ASYNC_RESET` selects asynchronous assertion) |
| `dcfifo` | Asynchronous FIFO with Gray pointers synchronized in both directions (`rdsync_delaypipe` − 2 stages, at least 2) |
| `altsyncram`, `altera_syncram` | Port A on `clock0`; port B on `clock1` when `address_reg_b` or `outdata_reg_b` is `"CLOCK1"`, otherwise on `clock0`; per-port write arrays as for block RAM |
| `altddio_in`, `altddio_out` | DDR input (falling-edge capture) and output registers |
| `altpll` | `clk[n]` are clocks derived from `inclk[0]`, period = input period × `clkN_divide_by` / `clkN_multiply_by`; the input period comes from the input clock or from `inclk0_input_frequency` (ps); `locked` has no clock domain |
| `altera_pll` | `outclk[n]` derived from `refclk`; period ratio = `reference_clock_frequency` / `output_clock_frequencyN` (strings such as `"125.000000 MHz"`); `locked` has no clock domain |

## Lattice

| Primitive | Model |
|---|---|
| `EHXPLLL` (ECP5) | `CLKOP`, `CLKOS`, `CLKOS2`, `CLKOS3` derived from `CLKI`: f(VCO) = f(CLKI) × `CLKFB_DIV` × DIV(feedback output) / `CLKI_DIV`, f(CLKx) = f(VCO) / `CLKx_DIV`; the feedback output is selected by `FEEDBK_PATH` (`CLKOP`, `CLKOS`, `CLKOS2`, `CLKOS3`, or the `INT_` variants); input period from the input clock or `FREQUENCY_PIN_CLKI` (MHz); `LOCK` has no clock domain |
| `SB_PLL40_CORE`, `SB_PLL40_PAD` (iCE40) | `PLLOUTCORE`/`PLLOUTGLOBAL` derived from the reference: f = f(ref) × (`DIVF`+1) / ((`DIVR`+1) × 2^`DIVQ`); `LOCK` has no clock domain |
| `SB_GB`, `SB_DFF`, `SB_DFFE`, `SB_DFFR`, `SB_DFFS`, `SB_DFFER` (iCE40) | Global buffer (wire) and flip-flops |
| `IDDRX1F`, `ODDRX1F` (ECP5) | DDR input (falling-edge capture) and output registers on `SCLK` |
| `DP16KD` (ECP5) | True dual-port RAM: port A on `CLKA`, port B on `CLKB`, per-port write arrays as for Xilinx block RAM; bit-level ports (`DIA0`…, `ADA0`…, `DOA0`…) |
| `SB_RAM40_4K`, `SB_RAM40_4KNR`, `SB_RAM40_4KNW`, `SB_RAM40_4KNRNW` (iCE40) | Write port on `WCLK`/`WCLKN`, read port on `RCLK`/`RCLKN` (N: falling edge) |

## Gowin

| Primitive | Model |
|---|---|
| `SDPB` | Semi dual-port RAM: write port on `CLKA`, read port on `CLKB` |
| `DPB` | True dual-port RAM: port A on `CLKA`, port B on `CLKB`, per-port write arrays |
| `rPLL`, `PLLVR` | `CLKOUT`/`CLKOUTP` derived from `CLKIN`: f = f(in) × (`FBDIV_SEL`+1) / (`IDIV_SEL`+1); `CLKOUTD` = `CLKOUT` / `DYN_SDIV_SEL`, `CLKOUTD3` = `CLKOUT` / 3; input frequency from the input clock or `FCLKIN` (MHz); `LOCK` has no clock domain |

Generic Gowin cell names (`DFF`, `DFFE`, `CLKDIV`, …) are deliberately not modelled: they collide with common user module names, and a missing user module must remain an error. Gowin `IDDR`/`ODDR` are not modelled either: the names are the Xilinx cells.

## Not modelled

These primitives are still reported as `FE-UNKNOWN-MODULE`:
- Xilinx: `ICAPE2`/`ICAPE3`, `STARTUPE2/3`, `PCIE*`, `CMAC*`, `HBM*`;
- Intel: transceiver IP, `altlvds`, `altiobuf`;
- Lattice: SERDES (`DCUA`), gearing DDR (`IDDRX2F`, `ODDRX2F`, …), `PDPW16KD`, iCE40 `SB_IO`; Gowin: `IDDR`/`ODDR` (name clash with Xilinx), `SP`, `pROM`, SERDES; Microchip primitives.

For each one you can:
- provide your own behavioral model in the sources (it replaces the built-in lookup), or
- leave it as an unresolved instance, which is analyzed conservatively and listed as `IR-UNRESOLVED-INSTANCE`.
